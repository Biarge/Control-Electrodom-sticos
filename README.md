# Control Electrodomésticos

Agenda para registrar encargos de electrodomésticos.

## Funciones
- Nuevo registro de cliente.
- Uno o varios electrodomésticos por encargo.
- Categorías: Lavadora, Lavavajillas, Frigorífico, Placa, Horno, Secadora y TV.
- Campo especial «Cambio de puerta» para Frigorífico.
- Día y hora de colocación.
- Estado colocado.
- Estado pagado: verde si está pagado y rojo si no.
- Estado facturado.
- Edición y eliminación.
- Búsqueda y filtros.
- Los datos se guardan en el navegador mediante localStorage.

## Publicación
Es una aplicación estática y puede publicarse con GitHub Pages sin servidor.
